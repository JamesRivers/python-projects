## Python Project Height Restriction Ride

- This program checks if a person is tall enough to ride a roller coaster.
- It asks for the user's height in cm and compares it to the minimum height requirement.
- If they are smaller then the minimum height of 120cm they are not allowed to ride.
- if they are taller than 120cm  and smaller then 140cm they are allowed to ride but must be accompanied by an adult.
- If they are taller than 140cm they are allowed to ride alone.
- There is a maximum ride capacity of 8 people
